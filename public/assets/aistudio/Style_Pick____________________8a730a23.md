현재 완성된 Style Pick 기본 앱은 그대로 유지하고, 여기에 **추천된 옷과 비슷한 실제 무신사 상품을 검색하는 기능만 추가**해줘.

기존 코드와 디자인을 불필요하게 다시 만들거나 변경하지 마.

## 핵심 기능

코디 추천 결과의 각 옷 아래에

`🛍️ 무신사에서 비슷한 상품 보기`

버튼을 추가해줘.

예:

👕 차콜 니트  
`🛍️ 무신사에서 비슷한 상품 보기`

👖 흑청 데님  
`🛍️ 무신사에서 비슷한 상품 보기`

👟 흰 스니커즈  
`🛍️ 무신사에서 비슷한 상품 보기`

버튼을 누르면 해당 옷과 비슷한 실제 무신사 상품을 검색해줘.

## 검색어 자동 생성

추천된 옷의:
- 색상
- 옷 종류
- 사용자가 선택한 스타일

을 활용해서 검색어를 만들어줘.

예:

차콜 니트 + 미니멀 스타일
→ `남성 미니멀 차콜 니트`

흑청 데님 + 스트릿 스타일
→ `남성 스트릿 흑청 데님`

흰 스니커즈
→ `남성 흰 스니커즈`

## 무신사 상품 검색

ReefAPI를 사용해줘.

엔드포인트:

`POST https://api.reefapi.com/musinsa/v1/search`

요청 예:

```js
{
  "query": "남성 미니멀 차콜 니트"
}
```

## API 키 보안

REEF_API_KEY는 반드시 서버 환경변수에서만 사용해줘.

`process.env.REEF_API_KEY`

브라우저 JavaScript, HTML, React 컴포넌트에 실제 API 키를 넣지 마.

프런트엔드에서는 직접 ReefAPI를 호출하지 말고 서버 API를 통해 호출해줘.

## 상품 결과

각 추천 옷당 실제 무신사 상품을 약 3개 보여줘.

상품 카드에는:
- 상품 사진
- 상품명
- 브랜드가 있으면 브랜드명
- 실제 가격
- 무신사 상품 페이지 링크

를 보여줘.

상품 클릭 시 새 탭에서 실제 무신사 상품 페이지가 열리게 해줘.

## 매우 중요한 정확성 규칙

상품명, 사진, 가격, URL은 반드시 동일한 ReefAPI 상품 객체에서 가져와줘.

예:
- title → 상품명
- image → 상품 사진
- final_price → 가격
- url → 상품 링크

실제 ReefAPI 응답 구조를 먼저 확인한 후 정확한 필드명을 사용해줘.

다른 상품의 사진과 상품명을 섞지 마.

API 응답에 없는 정보는 임의로 만들어내지 마.

## 내 옷장과 무신사 상품 구분

매우 중요:

내 옷장은 사용자가 실제로 가지고 있다고 등록한 옷이다.

무신사 검색 결과는 추천된 옷과 비슷한 구매 가능한 상품을 보여주는 참고 기능이다.

따라서 무신사 상품을 검색했다고 해서 자동으로 내 옷장에 추가하면 안 된다.

코디 추천도 계속 내 옷장에 있는 옷만 사용해야 한다.

## API 실패 처리

다음 상황에서도 기존 앱은 정상 작동해야 한다.

- API 키 없음
- ReefAPI 호출 실패
- 검색 결과 없음
- 이미지 오류
- 상품 URL 없음

실패 시:

`현재 무신사 상품 정보를 불러올 수 없습니다.`

라고 표시해줘.

가짜 상품을 만들어 보여주지 마.

## UI

무신사 상품 결과는 기본적으로 접어두고

`🛍️ 무신사에서 비슷한 상품 보기`

버튼을 누르면 펼쳐지도록 해줘.

기존 Style Pick의 디자인을 그대로 유지해줘.

가장 중요한 것은 기존의:
- 조건 선택
- 내 옷장
- 코디 추천
- 추천 점수
- Pixabay 사진
- 랜덤 코디 뽑기

기능을 절대 망가뜨리지 않는 것이다.

현재 프로젝트를 먼저 분석한 뒤 무신사 기능에 필요한 부분만 추가해줘.
