Style Pick이라는 코디 추천 웹앱을 만들어줘.

목적:
사용자가 계절, 날씨, 상황, 스타일, 선호 색상을 선택하고, 전체 의상 목록에서 자신이 가지고 있는 옷을 체크해 내 옷장에 추가하면, 내 옷장에 있는 옷만 사용해서 코디를 추천해주는 앱이다.

HTML, CSS, JavaScript 기반으로 만들고 모바일과 PC에서 모두 잘 보이는 반응형 UI로 구현해줘.

## 핵심 기능

### 1. 조건 선택
- 계절: 봄 / 여름 / 가을 / 겨울
- 날씨: 더움 / 따뜻함 / 선선함 / 쌀쌀함 / 추움 / 비
- 상황: 학교 / 데이트 / 친구와 약속 / 출근 / 운동 / 여행
- 스타일: 캐주얼 / 미니멀 / 댄디 / 스트릿 / 스포티 / 편안함
- 선호 색상: 블랙 / 화이트 / 그레이 / 네이비 / 베이지 / 브라운 / 블루 / 상관없음

### 2. 전체 의상 목록
카테고리는 다음처럼 나눠줘.

상의:
- 흰 반팔
- 검정 반팔
- 스트라이프 티셔츠
- 흰 셔츠
- 하늘색 셔츠
- 맨투맨
- 후드티
- 니트
- 카디건

아우터:
- 바람막이
- 블루종
- 데님 재킷
- 블레이저
- 트렌치코트
- 코트
- 패딩

하의:
- 흑청 데님
- 연청 데님
- 중청 데님
- 와이드 데님
- 검정 슬랙스
- 회색 슬랙스
- 베이지 슬랙스
- 카고팬츠
- 스웻팬츠
- 버뮤다팬츠

신발:
- 흰 스니커즈
- 검정 스니커즈
- 러닝화
- 로퍼
- 더비슈즈
- 워커
- 샌들
- 크록스

각 옷에는 다음 정보를 저장해줘.
- id
- 이름
- 카테고리
- 색상
- 계절
- 날씨
- 스타일
- 상황
- 이미지 검색용 영어 키워드

### 3. 내 옷장
처음 실행했을 때 내 옷장은 비어 있어야 해.

전체 의상 목록에서 사용자가 자신이 가진 옷을 체크해서 내 옷장에 추가하게 해줘.

내 옷장에서는:
- 보유 옷 확인
- 옷
